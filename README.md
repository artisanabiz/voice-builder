# Voice Builder

**Version 0.1.0 · Artisanabiz**

Build a reusable Writer skill from an existing writing voice using authorized samples, targeted questions, real writing trials and user feedback. The Builder and its generated Writer are separate skills.

- [Download the installable ZIP](https://github.com/artisanabiz/voice-builder/releases/download/v0.1.0/voice-builder-v0.1.0.zip)
- [English guide](voice-builder/README.md)
- [Ghid în română](voice-builder/GHID-RO.md)
- [Skill instructions](voice-builder/SKILL.md)
- [Use license](LICENSE.txt)

## Start

Keep the complete `voice-builder/` folder together and follow the English or Romanian guide. Ask your AI assistant to read SKILL.md and guide you from the beginning through Writer export. Uploading a ZIP does not automatically install a skill; file access and installation depend on the host. No Python compiler, API key, mailbox integration or tracking code is included.

Use only material you are entitled to share. Processing a local file through a cloud AI assistant is still processing by that provider. Exact excerpts need approval before export. Judge the actual writing; structural validity is not proof of voice resemblance or identical behavior across hosts.

## Utilizare

Păstrează dosarul complet `voice-builder/` și urmează ghidul în română. Builder-ul te ajută să creezi un Writer separat, pe baza mostrelor autorizate și a feedbackului tău. Nu publică și nu instalează automat fișierele. Verifică rezultatul înainte de utilizare sau distribuire.
